1. Install the complete package

Reuse an existing correct installation. Otherwise download APIxStar Grow v{{plugin_version}} ZIP and extract it into a fresh directory. The package contains both complete skills, their references and installation helpers; no GitHub checkout is needed.

curl --fail --location "{{plugin_download_url}}" --output growthpilot.zip
unzip growthpilot.zip -d growthpilot-install

On Windows, use Invoke-WebRequest and Expand-Archive instead. Read scripts/configure-workbuddy.mjs and scripts/install-skills.mjs before running them; keep them together in the extracted growthpilot/scripts/ directory.

Resolve the active configuration from WORKBUDDY_CONFIG_DIR when the running WorkBuddy provides it. Otherwise inspect Experts · Skills · Connectors → Connectors → Custom connectors → Add MCP → Configuration File Path. WorkBuddy editions use ~/.workbuddy/mcp.json or ~/.workbuddy-ai/mcp.json. The helper can resolve a single existing edition directory; if both exist and the environment is unset, confirm the active path in the client. Do not ask the user for a path that your tools already establish. Close an open configuration editor before writing the file.

Confirm the user skill directory independently from the running client's built-in skill-creator or supported skill-management information. WorkBuddy AI 5.8.4's bundled creator specifies ~/.codebuddy/skills/. Use that path only after checking the running client, expand it to an absolute path, and prefer user scope. Do not infer skills from the MCP directory or write several copies in guessed locations.

With Node.js LTS, run this once with the confirmed skill path. Add --config "/absolute/path/to/active/mcp.json" only when needed to select the active configuration:

node growthpilot-install/growthpilot/scripts/configure-workbuddy.mjs --server-url {{origin}}/mcp --skills-dir "/absolute/path/to/confirmed/user/skills"

The helper backs up changed MCP settings and preserves unrelated entries. It reuses a single matching endpoint under its existing name and returns serverName and configurationChanged; do not add another connector. It installs both complete skill folders:

  • growthpilot-website-research/SKILL.md and growthpilot-website-research/references/source-selection.md.
  • growthpilot-account/SKILL.md.

Identical skill files are reused. Managed updates are backed up in growthpilot-skill-backups/ beside the skills directory; unmanaged or locally modified folders require conflict resolution without overwriting the user's changes. For a skills-only repair, use --skills-only --skills-dir "/absolute/path/to/confirmed/user/skills". Do not register the bundled Codex/Claude marketplaces in WorkBuddy.

The command's configured_client_load_pending, client_oauth_pending and not_checked fields mean client status is unknown; they do not prove authorization is missing or that Trust must be clicked. The helper does not read credential caches, authorize an account or submit a query.

Update an existing installation

When the user requests an update, download the current package from this page into a fresh directory and run scripts/install-skills.mjs --skills-dir "/absolute/path/to/existing/user/skills". Preserve the existing endpoint and native authorization; do not rerun MCP setup merely to update skills. Back up managed updates, resolve local edits without overwriting, then verify both loaded skills and a real account call. No automatic update check or installation is required for first setup.
